# CareerLens

CareerLens is a data analytics project that analyses job postings to identify in-demand skills, career trends, and job-role fit.

## Project Structure
- `data/` - raw, intermediate, and processed datasets
- `notebooks/` - exploratory analysis
- `src/` - data collection, cleaning, extraction, taxonomy, and matching logic
- `sql/` - database schemas and analytical queries
- `dashboard/` - analytics dashboard
- `app/` - user-facing application
- `tests/` - automated tests
- `docs/` - project documentation
